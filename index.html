Setup

Verify before you analyze

Install from GitHub with one command — or grab the zip. Then run the provisioner: it checks Node, Binance Agent OS connectivity, all 9 Web3 launchers, and wallet sign-in state, and prints exact fix commands for your runtime.

1

Install the library (one command)

git clone https://github.com/hermesagent01/omb-skill-library.git ~/.hermes/skills/oh-my-binance

…or grab the zip from the button below and extract anywhere your agent can read.

2

Run the provisioner

node installer/provision.mjs

Checks Node, Agent OS connectivity, all 9 Web3 launchers, wallet sign-in state.

3

Connect Binance Agent OS

Pick your runtime in the panel — it prints the exact command. Read-only access; trading toggles stay OFF. Re-run the provisioner after connecting to confirm everything is AVAILABLE.
